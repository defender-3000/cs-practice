Git — это инструмент (программа) на вашем компьютере, а GitHub — это сайт (интернет-сервис) в сети.
Как они взаимодействуют?
1. Вы пишете код на компьютере и сохраняете его историю с помощью Git (git add, git commit).
2. Когда вы хотите показать код коллегам, сдать лабораторную или сделать резервную копию, вы отправляете (git push) его на GitHub.


Команды git diff и git diff --staged сравнивают разные состояния ваших файлов на пути от написания кода до его сохранения.
Вот четкое различие между ними:
1. Команда git diff
Сравнивает Рабочую директорию (вашу папку с файлами) и Индекс (зону ожидания).
• Что она показывает? Все изменения, которые вы сделали в файлах, но еще не добавили в индекс с помощью команды git add.
• Простыми словами: «Что я изменил в коде прямо сейчас, но еще не подготовил к сохранению?».
2. Команда git diff --staged (или git diff --cached)
Сравнивает Индекс (зону ожидания) и Последний коммит (последнее сохранение).
• Что она показывает? Изменения, которые вы уже добавили через git add. Это именно то, что попадет в историю проекта при следующем вызове git commit.
• Простыми словами: «Что именно я уже подготовил к сохранению и сейчас закоммичу?».


Использованные команды:
git status— Общая картина
Эта команда показывает статус вашего репозитория. Она отвечает на вопрос: «Что вообще происходит с файлами?».
• Она выводит список файлов, которые были изменены, удалены или созданы.
• Разделяет файлы на две категории: красные (изменения еще не подготовлены к сохранению) и зеленые (изменения добавлены в индекс и готовы к коммиту).
• Когда использовать: Постоянно, перед вводом любых других команд, чтобы сориентироваться.
git diff — Проверка незафиксированных изменений
Эта команда сравнивает вашу Рабочую папку (где вы пишете код) и Индекс (черновик Git).
• Она показывает конкретные строки кода, которые вы успели изменить или написать с момента последней подготовки.
• Важно: Она видит только те изменения, для которых вы еще не запускали команду git add.
• Когда использовать: Когда вы что-то написали и хотите вспомнить: «Так, а что именно я только что изменил в этом файле перед тем, как добавлять его в черновик?».
git diff --staged — Проверка готового коммита
Эта команда сравнивает Индекс (черновик Git) и Последний коммит (последнее сохранение).
• Она показывает точные изменения, которые вы уже добавили с помощью команды git add.
• Когда использовать: Прямо перед запуском git commit, чтобы перепроверить: «Что именно сейчас запишется в историю проекта, когда я нажму Enter?».
