# Шпаргалка по командам анализа в Git

### 1. В чём разница: git diff vs git show vs git log?

* **`git diff`** — показывает **текущие незакоммиченные изменения**. Это разница между вашим рабочим каталогом и последним сохранённым состоянием (индексом или коммитом). Отвечает на вопрос: *"Что я изменил в файлах прямо сейчас?"*
* **`git show`** — показывает **содержимое конкретного объекта** (обычно коммита). Вы увидите автора, дату, сообщение коммита и детальный список изменений (diff) конкретно для этого шага истории. Отвечает на вопрос: *"Что именно было сделано в этом конкретном коммите?"*
* **`git log`** — показывает **историю коммитов** в виде списка. Он выводит хэши, авторов, даты и сообщения коммитов, но по умолчанию не показывает изменённые строки кода. Отвечает на вопрос: *"Какова хронология разработки проекта?"*

---

### 2. Что делают специальные команды поиска?

* **`git log -S "текст"`** (Поиск "Кирка" / Pickaxe) — ищет коммиты, в которых указанная строка текста **появилась или исчезла** из файлов. Это незаменимо, если вам нужно найти, когда именно в проект добавили конкретную функцию или удалили важную переменную.
* **`git blame <файл>`** (Построчный анализ) — показывает выбранный файл построчно, выводя слева от каждой строки **автора, дату и хэш коммита**, который эту строку изменил последним. Отвечает на вопрос: *"Кто, когда и в каком коммите написал или отредактировал эту конкретную строчку кода?"*
